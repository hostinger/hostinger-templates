# Showcase

An art-book-inspired Astro portfolio for independent designers, illustrators, and photographers.

## Overview

Showcase presents six image-led projects in an asymmetric editorial grid, giving independent creatives a confident home for selected work without needing a CMS. The homepage moves from a typographic introduction through project work, studio approach, practical FAQs, and a direct enquiry invitation.

Every project has a direct-load case-study route generated from Markdown. The featured Afterimage House story adds an accessible draggable before-and-after comparison and a full-screen keyboard lightbox, creating a strong long-form example ready to replace with your own process.

## Features

- Six projects managed as typed Markdown content entries
- Static homepage and direct-load project routes
- Accessible before-and-after range slider with keyboard support
- Full-screen image lightbox with Escape, arrow-key navigation, and focus return
- Responsive asymmetric project grid for desktop and narrow mobile screens
- Four-question FAQ section with `FAQPage` JSON-LD
- Working `mailto:` enquiry links
- Local responsive image optimization through Astro assets

## Tech stack

- **Language:** TypeScript
- **Framework:** Astro 7
- **Build tool:** Astro
- **Styling:** Custom CSS with responsive design tokens
- **Content:** Astro content collections and Markdown
- **Linting:** ESLint flat config with Astro and TypeScript plugins

## Getting started

### Prerequisites

- Node.js 22.12 or newer
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open the local URL printed by the development server.

- `npm run dev` — start the local development server
- `npm run build` — type-check and create a production build
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build locally

## Personalizing

### Content and business data

Edit studio name, introduction, contact details, social links, availability, and FAQ copy in `src/content/site.ts`. Edit project metadata and case-study writing in `src/content/projects/*.md`.

### Branding and styles

Edit palette, typography, spacing, layout, motion, and responsive rules in `src/styles/global.css`. Core colors are grouped as custom properties at the top of that file.

### Images

Local source images live in `src/assets/images/`. Project cover images are referenced from each file in `src/content/projects/`; featured case-study images are imported by `src/components/BeforeAfter.astro` and `src/components/LightboxGallery.astro`. Use source images at least 1600 pixels wide, with generous room for responsive cropping.

### Routes and features

Homepage composition lives in `src/pages/index.astro`. Project routes are generated by `src/pages/projects/[id].astro`, and interactive behavior for comparison, lightbox, focus, and reveal effects lives in `src/scripts/interactions.ts`.

### Environment variables

This project does not require environment variables.
