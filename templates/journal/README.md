# Journal

A warm, print-inspired personal writing site for publishing standalone essays and connected series.

## Overview

Journal is a static editorial site for writers who want their work to feel considered without adding a publishing backend. Readers arrive at a complete index, see honest reading times, and open any of three long-form essays on a direct, shareable route.

The design borrows from small-press journals: warm newsprint, oxblood ink, blue-pencil marks, wide annotated margins, footnote-like metadata, and a comfortable serif reading measure. Two essays form a named series and provide contextual previous/next navigation, while the third stands alone.

## Features

- Homepage index with publication dates, descriptions, series labels, and reading times calculated from each Markdown body
- Three statically generated post routes with semantic articles, drop caps, 66-character reading measure, generous line height, and visible word counts
- Previous and next navigation between the two entries in the “Notes from the river” series
- Four-question accessible FAQ with matching `FAQPage` JSON-LD
- Original CSS and SVG registration marks, pencil annotations, and paper texture with no photography
- Skip link, visible keyboard focus, reduced-motion support, and responsive layouts tested down to 320px
- No newsletter provider, account, analytics, database, or environment setup

## Tech stack

- **Language:** TypeScript
- **Framework:** Astro
- **Build tool:** Astro static build
- **Styling:** Hand-written CSS with centralized design tokens
- **Content:** Astro content collection with Markdown posts and Zod validation
- **Linting:** ESLint flat configuration with Astro and TypeScript support

## Getting started


- `npm run dev` — start the local development server

- `npm run preview` — preview the production build locally

## Personalizing

### Content and business data

Edit the Markdown files in `src/content/posts/` to replace the essays. Their frontmatter controls titles, descriptions, dates, issue numbers, margin notes, and optional series membership. Site name, author, introduction, contact email, colophon, and FAQ copy live in `src/data/site.ts`. Reading times and word counts update automatically from each Markdown body.

### Branding and styles

Edit `src/styles/global.css`. Colors, font families, page gutters, and reading measure are design tokens in the `:root` block. The rest of the file contains header, homepage, article, series, FAQ, footer, and responsive rules. Keep `--reading-measure` near 60–70 characters for comfortable long-form reading.

### Images

This project uses no raster images. Original registration marks and marginal drawings are inline SVG in `src/components/SiteHeader.astro` and `src/pages/index.astro`; paper grain and all other print effects are CSS in `src/styles/global.css`. The site icon is `public/favicon.svg`.

### Routes and features

The homepage is `src/pages/index.astro`. Dynamic static post routes are generated by `src/pages/posts/[...id].astro` from the collection configured in `src/content.config.ts`. Shared page framing lives in `src/layouts/BaseLayout.astro`; article composition is in `src/layouts/PostLayout.astro`. Reading calculations live in `src/utils/readingTime.ts`, and series ordering lives in `src/utils/series.ts`.

### Environment variables

This project does not require environment variables.
