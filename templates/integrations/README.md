# Relay Integrations

A static partner directory for the fictional Relay workflow automation ecosystem.

## Overview

Relay Integrations helps product teams present a growing ecosystem of workflow connections in a directory that remains useful at a glance. Visitors can search and filter eight partners, understand each trigger-to-action route, and open a dedicated integration page directly.

Every detail route includes use cases, setup guidance, FAQs, and a partner contact path. The site is fully prerendered for simple static hosting and does not require a partner portal, backend, or environment configuration.

## Features

- Search integrations by partner name, category, or workflow summary.
- Filter the directory with accessible category controls and live result counts.
- Browse eight static detail routes with direct-load support.
- Review trigger/action specs, use cases, setup steps, and integration-specific FAQs.
- Publish `FAQPage` structured data on the index and every detail page.
- Contact partnerships through prefilled `mailto:` links.
- Use responsive layouts designed for desktop, 390px, and 320px widths.

## Tech stack

- **Language:** TypeScript
- **Framework:** Astro
- **Build tool:** Astro
- **Styling:** Custom CSS with shared design tokens and responsive breakpoints
- **Content:** Astro content collections with Markdown entries and Zod validation

## Personalizing

### Content and business data

Edit partner names, categories, summaries, use cases, setup steps, and FAQs in `src/content/integrations/*.md`. Edit site navigation, the partnership email, and homepage FAQs in `src/content/site.ts`.

### Branding and styles

Edit colors, typography, spacing, layout, and responsive breakpoints in `src/styles/global.css`. Shared design tokens are at the top of that file.

### Images

Original partner symbols live in the local SVG sprite at `public/icons/integrations.svg`. Add a symbol with a unique ID, then reference that ID in the integration Markdown `icon` field. The template does not use raster images or external photography.

### Routes and features

The homepage is composed in `src/pages/index.astro`. Integration pages are generated by `src/pages/integrations/[id].astro` from Markdown entries in `src/content/integrations/`. Search and category filtering live in `src/components/IntegrationDirectory.astro`.

### Environment variables

This project does not require environment variables.
