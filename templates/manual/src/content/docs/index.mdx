## Why Tapeline

<CardGrid stagger>
	<Card title="Capture everything" icon="approve-check">
		Every request that reaches the listener is appended to a plain-text store
		on your machine — headers, body, and timing. Nothing is uploaded anywhere.
	</Card>
	<Card title="Inspect the real payload" icon="magnifier">
		`tapeline tail` streams captured events with method, path, event name, and
		response status, and `--json` gives you the full request for close reading.
	</Card>
	<Card title="Replay until it passes" icon="rocket">
		`tapeline replay` resends a captured event byte for byte — original
		signature headers included — so you can fix a failing handler without
		begging the provider for another delivery.
	</Card>
	<Card title="Script every step" icon="setting">
		Stable exit codes, NDJSON export, and `--json` output make Tapeline easy
		to wire into test scripts and CI smoke checks.
	</Card>
</CardGrid>
